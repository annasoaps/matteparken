# Novemberträd till Matteparken 🍂

Ladda upp fyra genomskinliga PNG-filer här med exakt dessa namn:

- `ek.png` – novemberek med fallna löv
- `bjork.png` – novemberbjörk med fallna löv
- `tall.png` – novembertall med kottar
- `gran.png` – novembergran med kottar

Novemberkoden i `november_trees.js` använder dessa automatiskt under november. Om en fil ännu saknas visas en tillfällig höstvariant. Övriga årstiders originalsprites ändras inte.
